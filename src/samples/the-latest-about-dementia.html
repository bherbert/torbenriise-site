How to add a sample chapter for The Latest About Dementia: That You Need to Know

This window is ready for an excerpt. The text you see here is a placeholder; it lives in its own file, src/samples/the-latest-about-dementia.html, inside the website folder.

  1. Open the file src/samples/the-latest-about-dementia.html in a plain-text editor such as TextEdit (Format → Make Plain Text), BBEdit or VS Code. Avoid Word, which adds hidden formatting.
  2. Delete everything in it, including this note.
  3. Paste the chapter, wrapping each paragraph in <p> … </p>. A chapter title can go in <h3> … </h3>: 
    <h3>Chapter One</h3>
<p>The first paragraph of the chapter…</p>
<p>The next paragraph…</p>
  4. Save and publish. Rebuild the site (npm run build) and upload it. The excerpt then appears here, already formatted for reading.

Easier option: send the chapter as a Word file or plain text to whoever looks after the website, and they can drop it in.

Tips: one chapter or a few thousand words works well; the window scrolls. If a publisher holds rights to the book, check that an excerpt is allowed.
